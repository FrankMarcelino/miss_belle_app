 📊 ORDEM CORRETA DE DELEÇÃO - RESPEITANDO FOREIGN KEYS
═══════════════════════════════════════════════════════════════════════

Ao deletar dados, SEMPRE respeite esta ordem para evitar erros de FK:


┌─────────────────────────────────────────────────────────────────────┐
│ 1️⃣  cash_register_transactions                                      │
│    • Referencia: appointments (appointment_id)                      │
│    • Referencia: cash_register_closings (closing_id)                │
└─────────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────────┐
│ 2️⃣  cash_register_closings                                          │
│    • Referencia: profiles (professional_id)                         │
└─────────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────────┐
│ 3️⃣  appointments                                                     │
│    • Referencia: procedures (procedure_id)                          │
│    • Referencia: patients (patient_id)                              │
│    • Referencia: profiles (professional_id, created_by)             │
└─────────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────────┐
│ 4️⃣  patients                                                         │

└─────────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────────┐
│ 5️⃣  professional_procedures                                          │
│    • Referencia: profiles (professional_id)                         │
│    • Referencia: procedures (procedure_id)                          │
└─────────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────────┐
│ 6️⃣  procedures                                                       │

═══════════════════════════════════════════════════════════════════════
 ⚠️  ERROS COMUNS
═══════════════════════════════════════════════════════════════════════

❌ Erro: "violates foreign key constraint appointments_procedure_id_fkey"
   Causa: Tentou deletar procedures antes de appointments
   Solução: Delete appointments primeiro

❌ Erro: "violates foreign key constraint cash_register_transactions_appointment_id_fkey"
   Causa: Tentou deletar appointments antes de transactions
   Solução: Delete transactions primeiro

❌ Erro: "violates foreign key constraint patients_professional_id_fkey"
   Causa: Tentou deletar profiles antes de patients
   Solução: Delete patients primeiro

═══════════════════════════════════════════════════════════════════════
 💡 DICA: USAR CASCADE
═══════════════════════════════════════════════════════════════════════

Se quiser deletar automaticamente registros relacionados, use CASCADE
na definição das foreign keys:

  FOREIGN KEY (procedure_id) REFERENCES procedures(id) ON DELETE CASCADE

Mas CUIDADO: pode deletar dados importantes sem querer!
